## S-01 [MEDIUM] Gövde token denetiminden önce ayrıştırılıyor; "bu iş bunu kapatır" fazla iddialı
- Yer: FastAPI `routing.py:224-228` (gövde okuma) ve `:269` (`solve_dependencies`); `require_api_token` router bağımlılığı (`backend/app/main.py:26`, `backend/app/core/auth.py:11`).
- PoC: token'sız + `Origin: http://evil.example`, `/api/sessions/<uuid>/import/zip`, 1 dosya → 401; 1001 dosya → 400 "Too many files" (ayrıştırıcı yetkiden önce); `/api/sessions/preview` bozuk JSON → 422 `json_invalid`.
- CORS: `multipart/form-data` ve `text/plain` simple request; CORSMiddleware isteği engellemez.
- Yükseltme sonrası kalan yüzey: (a) token'sız multipart parçaları 1 MB sonrası diske yazılır, toplam sınır yok (`starlette/formparsers.py:209`; `MAX_UPLOAD_BYTES` yetkiden sonra) → başka siteden tetiklenebilen disk doldurma; (b) `text/plain` gövde sınırsız belleğe okunur; (c) gelecekteki ayrıştırıcı açıkları token'sız erişilebilir.
- Etki: yalnız erişilebilirlik (DoS).
- Düzeltme: §12 "bilinen kayıtları kapatır; ayrıştırma-öncesi-yetki yüzeyi kalır"; PB-5'e karakterizasyon (token'sız 1001 dosya → bugün 400; 1 dosya → 401); ayrı iş (SPEC-003 adayı, T-5 sonrası): `/api/*` için routing öncesi token denetleyen ASGI middleware (health ve OPTIONS hariç), `Content-Length` ve stream üst sınırı, isteğe bağlı TrustedHost.

## S-04 [LOW] Test konteynerinde gerçek `ENCRYPTION_KEY` yüklü
- `docker-compose.yml:35` `env_file: .env`; `scripts/test.sh:13`; `conftest.py:14` `setdefault` gerçek değeri ezmiyor; `.env:6`'da gerçek anahtar var (değer gösterilmedi).
- Etki: repoya gerçek anahtarla üretilmiş ciphertext girebilir.
- Düzeltme: sabit token'lar sentetik anahtarla açıkça (`monkeypatch.setattr(settings,"encryption_key","golden-key-A")` ya da `Fernet(_derive_key("golden-key-A"))`) ve `.env`'siz `docker run --rm --network none -e ENCRYPTION_KEY=<sentetik>` ile üretilir; düz metin gerçek sessionid'ye benzemez; `# gitleaks:allow` yalnız token satırlarına.
